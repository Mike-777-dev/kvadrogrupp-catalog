ГОТОВАЯ ПУБЛИКАЦИЯ: ГДЕ ПОЛУЧИТЬ ПУБЛИЧНУЮ HTTPS-ССЫЛКУ
========================================================

Ниже два самых быстрых способа. Выберите один.


ВАРИАНТ А — GITHUB PAGES (бесплатно, ссылка навсегда)
-----------------------------------------------------
1. Зайдите на https://github.com и создайте репозиторий, например
   `kvadrogrupp-catalog`. Сделайте его Public. Остальные поля можно
   оставить пустыми.

2. В репозитории нажмите `Add file` → `Upload files`.
   Перетащите **все файлы из папки kvadrogrupp-pwa** в корень
   (НЕ саму папку, а её содержимое: index.html, manifest.webmanifest,
   sw.js, иконки, netlify.toml, .nojekyll и т.д.).
   Нажмите `Commit changes`.

3. Зайдите `Settings` → `Pages` (в левом меню).
   В блоке `Build and deployment`:
     Source:  Deploy from a branch
     Branch:  main  (или master — как у вас называется)
     Folder:  / (root)
   Нажмите `Save`.

4. Через 1–2 минуты вверху страницы Pages появится ссылка:
   https://ВАШ-ЛОГИН.github.io/kvadrogrupp-catalog/

5. Откройте её в Chrome (Android) или Safari (iPhone) и устанавливайте
   по инструкции из README.txt.

Если в Branch не появляется main — обновите страницу через минуту
или явно выберите другую ветвь из списка.


ВАРИАНТ Б — NETLIFY DROP (самый быстрый, без терминала)
-------------------------------------------------------
1. Откройте https://app.netlify.com/drop
   (или https://drop.netlify.com — он перенаправит).

2. Войдите через GitHub/Google или создайте аккаунт — это занимает минуту.

3. Распакуйте `kvadrogrupp-pwa.zip` и перетащите **папку
   kvadrogrupp-pwa** целиком в окно браузера.
   Netlify сам загрузит файлы и сразу даст ссылку вида:
   https://something-random-123.netlify.app

4. Чтобы ссылка была красивой:
   Site overview → `Site settings` → `Change site name` →
   введите, например, `kvadrogrupp-catalog` → Save.
   Получится: https://kvadrogrupp-catalog.netlify.app

5. Готово. Файл `netlify.toml` уже лежит в папке и задаёт правильные
   заголовки для манифеста и service worker.


ПРОВЕРКА ПОСЛЕ ПУБЛИКАЦИИ
-------------------------
Откройте ссылку на телефоне:
  • Android, Chrome → должно появиться «Установить приложение».
  • iPhone, Safari → «Поделиться» → «Добавить на главный экран».

Чтобы проверить офлайн: откройте сайт один раз с интернетом,
включите авиарежим и откройте иконку ещё раз — каталог должен
открыться из кэша.


ПАРОЛЬ И НАСТОЯЩАЯ ЗАЩИТА
-------------------------
В index.html встроен экран входа с паролем. Он скрывает каталог
от случайных посетителей и работает даже офлайн. Пароль хранится
в виде хэша, но это всё равно клиентская проверка: при желании
содержимое HTML можно достать из исходника.

Если нужен реальный доступ только для своих — поставьте защиту
на уровне сервера. Самый простой бесплатный вариант:

  Cloudflare Pages + Cloudflare Access (Zero Trust)
  1. Загрузите папку kvadrogrupp-pwa в Cloudflare Pages
     (Direct Upload или через подключённый GitHub).
  2. Получите ссылку вида https://kvadrogrupp-catalog.pages.dev.
  3. Зайдите в Cloudflare Zero Trust → Access → Applications.
  4. Add an application → Self-hosted → введите ваш pages.dev-домен.
  5. В правиле доступа выберите:
       Allow → Emails → перечислите e-mail сотрудников
     или Single sign-on / One-time PIN.
  6. Save. Теперь до ввода почты/кода страница вообще не отдаётся.

Бесплатный тариф Cloudflare Access покрывает до 50 пользователей —
для каталога этого достаточно. Внутренний пароль в index.html можно
оставить как дополнительный экран.
